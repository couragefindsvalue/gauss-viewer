# 📘 Gauss Contest Viewer

> A modern web viewer for the University of Waterloo Gauss Math Contest.  
> 滑铁卢大学高斯数学竞赛的现代化在线查看器。

## ✨ Features / 功能特性

| 功能 | 说明 |
|---|---|
| 📄 **PDF Auto-Cropping** | 自动解析 PDF，跳过封面，精准切分题目与答案 |
| 🔄 **Questions / Solutions Toggle** | 一键切换题目与解答，保留滚动位置 |
| 🔍 **Smooth Zoom** | 支持双指捏合、按钮缩放、双击复位（50%–400%） |
| ✏️ **Whiteboard** | 内置白板，支持 5 种颜色、橡皮擦、撤销、按页保存 |
| 📚 **Multi-Year Archive** | 内置 2016–2026 年历年真题 |
| 📱 **Responsive Design** | 完美适配手机、平板、电视及桌面端 |
| ⌨️ **Keyboard Shortcuts** | ← / → 翻页，+ / − 缩放，0 复位 |
